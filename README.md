# Cadence

**Cadence** is a mobile-first communication practice website built around one simple idea: speaking improves through practice.

It gives users a place to work on their voice, articulation, fluency, spontaneous speaking, and confidence without requiring an account or complicated setup.

The main feature is a random speaking system that gives users a topic and a speaking challenge, encouraging them to think and speak without preparing everything beforehand.

---

## What Cadence Does

Cadence brings several speaking exercises into one place:

* Random speaking topics
* Timed speaking challenges
* Voice and resonance exercises
* Tongue twisters
* Fluency practice
* Filler-word practice
* Quick speaking questions
* Vocabulary practice
* Daily practice routines
* Communication-focused YouTube channels
* Local practice progress

The website is designed to be useful even if someone only has a few minutes.

---

## Main Feature

### Random Speaking Wheel

The center of Cadence is the speaking wheel.

Instead of choosing what to talk about, the user spins the wheel and gets a random topic.

A session can look like:

> **Topic:**
> What is one skill everyone should learn before adulthood?

> **Challenge:**
> Speak for 5 minutes. Give three reasons and include one personal example.

This removes the need to decide what to practice and makes spontaneous speaking part of the routine.

The system contains more than 100 speaking topics covering different types of conversation.

### Topic Categories

Topics can include:

* Personal experiences
* Opinions
* Storytelling
* Everyday situations
* Imagination
* Debates
* Decision making
* Explanation
* Persuasion
* Self-reflection
* Social situations
* Education
* Technology
* Work
* Relationships
* Society

The wheel itself remains visually simple on smaller screens while the actual topic database provides much more variety.

# Speaking Challenges

A topic is paired with a challenge so that the user is not simply reading a question and moving on.

Challenges can include:

* Speak for 1 minute
* Speak for 2 minutes
* Speak for 5 minutes
* Speak for 10 minutes
* Speak for 15 minutes
* Start speaking immediately
* Give three reasons
* Give a personal example
* Explain both sides
* Defend an unpopular opinion
* Tell a story
* Explain something simply
* Speak without filler words
* Build an introduction, main point, and conclusion
* Convince the listener
* Change your position halfway through

The combination of topics and challenges keeps repeated practice from feeling identical.

---

# Speaking Session

Once a user starts a challenge, Cadence moves into a focused practice view.

The session displays:

* The topic
* The challenge
* The selected duration
* A timer
* Pause controls
* Reset controls
* Finish controls

The interface intentionally removes unnecessary elements during an active session.

The purpose is simple:

**Read the prompt, start the timer, and speak.**

After finishing, the session is recorded locally as completed practice.

# Voice Training

Cadence includes a dedicated voice-training area for users who want to work on vocal control, resonance, articulation, and awareness.

The exercises use sustained sounds and simple sound combinations.

Examples include:

* ZEEEE
* VVVVV
* MMMMM
* NNNNN
* NG
* OOOOO
* AAAAA
* EEEEE
* UUUUU
* LLLLL
* RRRRR
* WOOOO
* ZEE-ZAH-ZOO
* ME-MAY-MY-MO-MOO
* LA-LE-LI-LO-LU
* VEE-VAY-VIE-VO-VOO

Each exercise contains:

* The sound
* Instructions
* Recommended duration
* Repeat count
* A practice timer
* Reset controls

Exercises remain compact until the user chooses to open one.

### Voice Exercise Approach

Cadence does not promise to physically change someone's vocal anatomy or guarantee a permanently deeper voice.

The exercises are presented as practice for things such as:

* Resonance awareness
* Vocal control
* Articulation
* Coordination
* Consistency
* Speaking preparation

Users should stop an exercise if it causes pain, strain, or persistent discomfort.

# Tongue Twisters

The articulation section contains a collection of tongue twisters designed for repeated practice.

Instead of displaying every tongue twister immediately, Cadence keeps them hidden behind an interaction.

A user can select a practice item and reveal the complete text.

Each item can provide:

* Tongue twister
* Difficulty
* Target sound
* Recommended repetitions
* Practice timer

The collection covers different pronunciation patterns, including sounds such as:

* R / L
* S / SH
* TH
* P / B
* T / D
* Fast consonant combinations

Users can start slowly, focus on clarity, and gradually increase speed.

# Quick Practice Modes

Cadence also provides shorter ways to practice speaking.

## Random Question

Receive a question and answer without preparing a written response.

The goal is to practice organizing thoughts while speaking.

## No-Filler Challenge

Speak for a selected amount of time while paying attention to common fillers such as:

* um
* uh
* like
* basically
* you know

Cadence does not claim to automatically detect filler words unless speech-recognition functionality is actually implemented.

## Story Mode

Receive a starting point and create a story around it.

This encourages:

* Structure
* Description
* Imagination
* Continuity
* Spontaneous thinking

## Explain It

Take a complicated subject and explain it as simply as possible.

This focuses on clarity rather than using complicated vocabulary.

# Daily Practice

Cadence can generate a small daily routine so users do not have to decide what to practice each time.

A routine might contain:

1. Voice warm-up
2. Articulation exercise
3. Random speaking topic
4. Fluency challenge
5. Short reflection

The routine can change according to the day.

The aim is to make practice easier to start.

# Vocabulary Practice

Cadence includes a small vocabulary practice area.

A word can be presented with:

* Meaning
* Example usage
* Speaking prompt

The user is then encouraged to use the word naturally while speaking.

The focus is not memorizing long word lists.

It is using new vocabulary during actual speech.

# Progress

Cadence does not require an account.

Instead, basic practice information can be stored locally in the browser using `localStorage`.

Possible statistics include:

* Sessions completed
* Total practice time
* Topics completed
* Voice exercises completed
* Tongue twisters practiced
* Current practice streak

This keeps the experience simple while still allowing the user to see whether they are practicing consistently.

No server-side account is required for this functionality.

# Mobile-First Design

Cadence is designed primarily for smartphones.

The interface is built around common mobile screen sizes and touch interaction rather than treating mobile as a smaller desktop layout.

The design focuses on:

* Comfortable touch targets
* Readable typography
* Short interaction paths
* Minimal clutter
* Clear navigation
* Focused practice screens
* Vertical layouts
* Smooth transitions
* Limited horizontal scrolling

Desktop layouts adapt the same system rather than becoming a completely separate website.

# Dynamic Content

Cadence is not intended to be a collection of static HTML cards.

Content is stored as JavaScript data and rendered dynamically.

Typical datasets include:

```javascript
topics[]
challenges[]
voiceExercises[]
tongueTwisters[]

```

This makes it easier to:

* Randomize content
* Add new exercises
* Filter practice material
* Avoid repeated topics
* Track completed items
* Reuse components

# Random Topic Selection

The speaking system should avoid immediately returning recently used topics.

A small history can be maintained locally.

For example:

```text
Current topic
↓
Practice
↓
Store topic in recent history
↓
Next spin
↓
Avoid recently selected topics
```

This keeps repeated sessions more varied.

# Browser Storage

Where progress is supported, Cadence uses browser `localStorage`.

Stored information can include practice statistics and preferences.

This information belongs to the browser/device being used.

Clearing browser storage may remove locally saved progress.

---

# Privacy

Cadence does not require an account for its core functionality.

The application should not request personal information simply to allow someone to practice speaking.

If local storage is used for progress, that information remains stored in the user's browser rather than requiring an online profile.

Any external resources, such as YouTube links, are subject to the policies of those external services.

# Project Goals

Cadence is built around a few straightforward principles:

### Practice over preparation

Speaking ability improves through actually speaking, not only reading about communication.

### Consistency over intensity

A short practice session is still useful if it is done regularly.

### Variety over repetition

Random topics and different challenges prevent every session from becoming the same exercise.

### Simplicity over clutter

The user should be able to open Cadence and begin practicing without learning how the website works first.

### Useful interaction over decoration

Animations and interface elements should serve a purpose.
